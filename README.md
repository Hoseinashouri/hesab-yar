# حساب‌یار - یادآور و حسابداری شخصی 🔐

یک مینی اپ تلگرام برای مدیریت مالی شخصی + سیستم یادآور هوشمند

## 🚀 شروع سریع

### ۱. ساخت ربات تلگرام
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام `/newapp` بده
2. نام و توضیحات رو وارد کن
3. یک HTTPS URL برای اپلیکیشن انتخاب کن
4. توکن رباتت رو از BotFather بگیر

### ۲. نصب依赖
```bash
cd D:\Telegram
npm install
```

### ۳. تنظیم متغیرهای محیطی
فایل `.env` بساز:
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
APP_URL=https://your-domain.com
PORT=3000
```

### ۴. اجرای پروژه
```bash
# حالت توسعه (همزمان bot و web)
npm run dev

# فقط بیلد
npm run build
```

## 📱 ویژگی‌ها

### 💰 حسابداری شخصی
- ثبت درآمد و هزینه
- دسته‌بندی خودکار (غذا، حمل‌ونقل، خرید، قبوض، سلامت...)
- نمایش موجودی لحظه‌ای
- آمار و نمودار هزینه‌ها

### 🔔 سیستم یادآور
- تنظیم یادآور برای پرداخت‌ها
- نوتیفیکیشن خودکار در تلگرام
- سطوح اولویت (بالا / متوسط / پایین)
- بررسی خودکار هر دقیقه

### 🎨 رابط کاربری
- طراحی RTL فارسی
- پشتیبانی از تم تلگرام (روشن/تاریک)
- انیمیشن‌های نرم
- Haptic feedback

## 🔧 API Endpoints

| Method | Path | توضیح |
|--------|------|-------|
| POST | `/api/sync` | سینک داده‌ها از مینی اپ |
| GET | `/api/data/:userId` | دریافت داده‌های کاربر |

## ⚙️ دستورات ربات

| دستور | عملکرد |
|-------|--------|
| `/start` | شروع و باز کردن مینی اپ |
| `/help` | نمایش راهنما |
| `/add` | ثبت سریع هزینه |
| `/income` | ثبت درآمد |
| `/balance` | مشاهده موجودی |
| `/remind` | تنظیم یادآور |
| `/categories` | لیست دسته‌بندی‌ها |
| `/clear` | پاک کردن داده‌ها |

## 🌐 دیپلوی

برای انتشار عمومی:
1. از Vercel/Render/Heroku استفاده کن
2. SSL certificate الزامی است (تلگرام قبول نمیکنه)
3. URL رو در BotFather ثبت کن

## 📝 نکات مهم

- در production حتماً `initData` رو validate کن
- داده‌ها فعلاً در memory نگهداری میشن — برای production از SQLite/PostgreSQL استفاده کن
- مینی اپ باید حتماً HTTPS باشه
